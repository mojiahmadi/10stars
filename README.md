# 🌟 10-Star Student Assessment Platform
**سامانه هوشمند ارزیابی صلاحیت‌های بالینی و حرفه‌ای دانشجویان (مدل ده‌ستاره)**

<div dir="rtl">

این پروژه یک وب‌اپلیکیشن تعاملی و مبتنی بر سناریو است که برای ارزیابی مهارت‌های ده‌گانه دانشجویان علوم پزشکی و هوشبری طراحی شده است. این پلتفرم با ارائه یک رابط کاربری مدرن (Glassmorphism) و گیمیفای‌شده، فرآیند خشکِ ارزیابی را به یک تجربه جذاب تبدیل می‌کند و در نهایت یک کارنامه گرافیکی با قابلیت اشتراک‌گذاری به کاربر ارائه می‌دهد.

این سامانه با افتخار برای **انجمن علمی هوشبری دانشگاه علوم پزشکی تبریز** توسعه یافته است.

### ✨ ویژگی‌های کلیدی (Features)
* 🎯 **ارزیابی موقعیت‌محور (Scenario-based):** سنجش مهارت‌ها بر اساس سناریوهای واقعی بالینی.
* 📊 **تحلیل گرافیکی (Radar Chart):** رسم آنی نمودار تار عنکبوتی از نقاط قوت و ضعف دانشجو.
* 🖼️ **صدور کارنامه دیجیتال:** قابلیت دانلود کارنامه نهایی با کیفیت بالا (High-Res Image) جهت اشتراک‌گذاری.
* 🎨 **طراحی مدرن و واکنش‌گرا:** استفاده از افکت‌های Glassmorphism و کاملاً سازگار با موبایل و دسکتاپ.
* ⚡ **عملکرد سمت کاربر (Client-side):** بدون نیاز به دیتابیس و بک‌اند، با بالاترین سرعت پردازش.

### 🛠️ تکنولوژی‌های استفاده شده (Tech Stack)
* **توسعه رابط کاربری:** HTML5, Tailwind CSS
* **منطق برنامه:** Vanilla JavaScript
* **رسم نمودار:** [Chart.js](https://www.chartjs.org/)
* **تولید خروجی تصویر:** [html-to-image](https://github.com/bubkoo/html-to-image)
* **تایپوگرافی:** فونت زیبای [وزیرمتن (Vazirmatn)](https://rastikerdar.github.io/vazirmatn/)

### 🚀 نحوه استفاده (Usage)
این پروژه کاملاً ایستا (Static) است و برای اجرای آن نیازی به نصب هیچ پکیجی ندارید:
۱. فایل‌های پروژه را دانلود یا Clone کنید.
۲. فایل `index.html` (یا `assessment.html`) را در مرورگر خود (ترجیحاً Chrome یا Firefox) باز کنید.
۳. نام خود را وارد کرده و فرآیند ارزیابی سناریوها را آغاز کنید.

---

### 📋 لیست معیارهای ده‌گانه (The 10 Criteria)
در این سامانه دانشجویان بر اساس این ۱۰ معیار کلیدی سنجیده می‌شوند:
1. **ارائه‌دهنده (Provider):** ارائه مراقبت‌های ایمن و استاندارد بالینی.
2. **تصمیم‌ساز (Decision Maker):** انتخاب بهترین رویکرد در شرایط اورژانسی.
3. **ارتباط‌گیر (Communicator):** برقراری ارتباط موثر با بیمار و تیم درمان.
4. **مدیر (Manager):** برنامه‌ریزی زمان و مدیریت منابع در محیط کار.
5. **رهبر (Leader):** هدایت تیم و الهام‌بخش بودن در کارهای گروهی.
6. **یادگیرنده (Learner):** تلاش مستمر برای به‌روزرسانی دانش علمی.
7. **معلم (Teacher):** انتقال موثر تجربیات به دانشجویان سال‌پایین‌تر.
8. **پژوهشگر (Researcher):** جستجوگری و بررسی مقالات برای حل چالش‌ها.
9. **تغییرساز مثبت (Positive Changer):** داشتن انرژی مثبت برای بهبود سیستم.
10. **کارآفرین (Entrepreneur):** ایده‌پردازی و خلق ارزش‌های نوین در حوزه سلامت.
